# ViniMap Logistics OS & Dashboard

![ViniMap Banner](public/vinimap_app_logo_1785236008840.jpg)

**ViniMap Logistics OS** é uma plataforma moderna e completa de logística urbana, gestão de frota, alocação inteligente de pedidos e monitoramento em tempo real de entregadores na Grande São Paulo.

## 🚀 Principais Funcionalidades

- 📍 **Mapa e Rastreamento em Tempo Real**: Localização ao vivo de entregadores e status detalhado das rotas em São Paulo e região.
- 📦 **Alocação e Otimização de Rotas**: Roteirização inteligente com ordenação de pontos e cálculo de frete por faixa de CEP.
- 💳 **Módulo Financeiro & DRE**: Gestão de contas a pagar e receber, repasse a entregadores, conciliação e DRE com suporte a Inteligência Artificial (Gemini API).
- 🔄 **Integração com Banco de Dados**: Suporte duplo a Firebase (Firestore) e Supabase (PostgreSQL), com ferramentas de importação e sincronização.
- 🐙 **Integração Nativa com GitHub**: Vinculação de conta OAuth, criação de repositórios no GitHub e sincronização do código-fonte em tempo real.
- 📱 **Painel de Controle e App do Condutor**: Interface responsiva e simulador de aplicativo móvel para motoristas e motociclistas.

## 🛠️ Tecnologias Utilizadas

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Motion.
- **Backend / Servidor**: Express.js, Node.js, Vite.
- **Banco de Dados & Cloud**: Firebase Firestore, Supabase PostgreSQL.
- **AI & Geocodificação**: Google GenAI (Gemini 2.5/3.0), OpenStreetMap Nominatim Engine.

## 🔧 Configuração e Instalação

```bash
# Instalar dependências
npm install

# Executar servidor de desenvolvimento
npm run dev

# Compilar para produção
npm run build
```
